# KickStart Kids

Android-приложение для домашних футбольных тренировок детей 7–13 лет (React + Capacitor). Офлайн, без аккаунтов, публикация только в RuStore. Язык общения и интерфейса — русский.

Перед работой прочитай:

- `docs/mvp-plan.md` — что делаем сейчас: текущий этап = первый с невыполненными `[ ]`. Отмечай выполненные задачи `[x]` в этом файле.
- `docs/architecture.md` — стек, структура, модель данных, бизнес-правила.
- `docs/design/` — макеты экранов; токены — `src/shared/styles/_tokens.scss`.

## Команды

```bash
npm run dev         # веб-версия в браузере (основной цикл разработки)
npm test            # Vitest
npm run typecheck   # tsc
npm run lint        # oxlint
npm run check       # всё сразу + сборка — запускать перед каждым коммитом
npm run cap:sync    # сборка + копирование в android/
npm run cap:open    # открыть Android Studio (сборка APK — на машине разработчика)
```

## Правила

- **Объём.** Делаем только то, что есть в MVP-колонке `docs/mvp-plan.md`. Всё из «Позже (1.1+)» — не реализовывать, даже если просто. Сомневаешься — спроси.
- **TypeScript strict**, без `any`. Zod 4: `z.email()`, а не `z.string().email()`.
- **Плагины Capacitor** — только через `src/shared/lib/platform`; у каждой обёртки есть веб-фолбэк, приложение должно работать в браузере.
- **Строки интерфейса** — только через i18n (`src/shared/i18n/ru.ts`), никаких литералов в JSX.
- **Стили** — SASS-модули + токены; цвета не хардкодить в компонентах.
- **Бизнес-логика** (календарь, уровни, серия, машина состояний таймера) — чистые функции/сторы Effector с юнит-тестами. Время в таймере — от `Date.now()`, не от тиков.
- **Данные пользователя** — со `SyncMeta` (`id`, `updatedAt`, `deletedAt?`), через слой репозиториев.
- **Доступность**: настоящие `<button>`/`<a>`, `aria-label` у иконочных кнопок, зоны нажатия ≥ 44 px, контраст текста ≥ 4.5:1.
- **Офлайн**: никаких сетевых запросов, внешних шрифтов и CDN.
- **Бренд FIFA** нигде не упоминать (ни в UI, ни в метаданных).
- `appId` и имя приложения — только в `src/shared/config/app.ts` (+ дубль в `capacitor.config.ts`, сверяется тестом).
- Перед коммитом — `npm run check` зелёный. Коммиты небольшие, по одной задаче из плана.
