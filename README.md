# KickStart Kids

Домашние тренировки для юных футболистов 7–13 лет: 12-недельная программа травмопрофилактики, работа с мячом, быстрые ноги и мобильность — с таймером, демо-видео и маскотом Кик.

Стек: React 19 + TypeScript + Vite, Capacitor 8 (Android), Effector, SASS, Zod, i18next, Vitest.

## Запуск

```bash
npm install
npm run dev        # в браузере
npm run check      # тесты, типы, линт, сборка
```

Android (нужны Android Studio и JDK 21):

```bash
npm run cap:sync
npm run cap:open   # Run ▶ на подключённом телефоне
```
