# Макеты экранов

Единый макет `KickStart Phone.dc.html` (Claude Design, светлая тема): все экраны приложения в одном файле, 390×844. Картинки Кика — `assets/kik-*-c2.png`, рантайм для просмотра — `support.js`.

Как смотреть:

- Экран выбирается свойством `start` (`onb1`, `onb2`, `onb3`, `home`, `library`, `exercise`, `timer`, `rest`, `done`, `calendar`, `profile`); режим — `mode` (`child` | `coach`). Запустить файл можно локально: `python3 -m http.server` в этой папке и открыть `KickStart Phone.dc.html` (шрифт грузится с Google Fonts только в макете; в приложении он локальный).
- Разметка — внутри `<x-dc>`; `{{name}}` — подстановки из `renderVals()`. Варианты `homeVar`/`timerVar` в файле фиксированы (`hv='B'`, `tv='C'`): реальный вариант Главной — «B», таймера — один.

Что в приложении сделано иначе (осознанно):

- **Контраст.** Серый для подписей `#62745B` из макета даёт 4.38:1 на поле, поэтому в токенах `#5B6C53`. Цвет `#A7BC97` годится только для декора и для подписей на тёмном (нижнее меню); на светлом фоне текстом не используется.
- **Подписи не мельче 11 px**, зоны нажатия не меньше 44 px (видимые кружки и поля в макете меньше — рисуются внутри зоны 44 px).
- **Экраны, которых нет в макете**, сделаны в том же стиле: обзор перед занятием, вступление к упражнению, «Приготовься», оценка техники, пауза, диалог завершения, «занятия сегодня нет».
- **Данные из программы, а не из макета.** Названия («Баланс и трюки», «Планка»), «15–20 сек», уровни и серия в макете условные; в приложении подставляются реальные упражнения из `docs/program.md`, а категории без нескольких уровней (техника, игры, мобильность) в профиле не показываются.
- **Онбординг — 3 шага.** Дату старта в «Старт программы» меняют кнопкой «Изменить» (пресеты и сетка месяца), PIN задаётся по нажатию на строку «PIN для взрослых» (дважды).
- **Календарь:** добавлены стрелки месяцев (программа идёт ~3 месяца), у выбранного дня — действия «Был», «Пропустить», «Перенести», «Отменить».
- **Экран упражнения:** для взрослого добавлен блок «Для взрослого» (ошибки, команда, переключатель уровней).
- Для 6-й категории «Мобильность» в макете нет цвета — добавлен бирюзовый.

Токены: `src/shared/styles/_tokens.scss`. Маскот: `src/shared/assets/kik/` (копии картинок из `assets/`).
