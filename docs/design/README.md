# Макеты экранов

Экспорт из канваса «KickStart Kids — приложение для юных футболистов» (Claude Design). Каждый `*.dc.html` — один экран 390×844 (альбомные — 844×390).

Как читать файл:

- Разметка — внутри `<x-dc>`; `{{name}}` — подстановки из метода `renderVals()` в `<script type="text/x-dc">` внизу файла. Там же все тексты (RU/EN) и цвета.
- `<sc-for list="{{items}}" as="item">` — цикл, `<sc-if value="{{cond}}">` — условие.
- `mode: 'child' | 'coach'` — два режима экрана.
- Запустить файлы как есть нельзя (нужен рантайм канваса) — это референс для вёрстки, а не код.

Отличия, которые нужно учесть при переносе в приложение:

- Шрифты подключаются локально, а не через Google Fonts.
- Полосатый фон `stripeTexture` будет заменён сгенерированными фонами (этап 1) с затемнением.
- Жёлтый манекен в макетах — заглушка: в приложении будут видео и превью с маскотом Кик (`Mascot.dc.html` — 2D-версия маскота).
- В `Onboarding2` один набор дней; в приложении нужно выбрать отдельно дни секции и дни домашних занятий.
- Альбомные макеты (`*Landscape`) — не в MVP.

Токены: `src/shared/styles/_tokens.scss`.
