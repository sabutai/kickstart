# Черновики недостающих текстов (на проверку владельцем)

**Статус: черновик. В приложение это НЕ попадает.** Тексты написаны мной (не из источника), потому что в `docs/program.md` у блоков Б–Г нет полей «Зачем», «Ошибки» и «Команда ребёнку». Правило проекта — методику не придумывать, поэтому ничего отсюда не подключено: нужно ваше «да» или правки по каждой строке.

Как использовать: поправьте или вычеркните строки, отметьте утверждённые — и я перенесу их в `src/content/program.json` отдельным коммитом. Что можно не утверждать: любое поле любого упражнения (приложение прекрасно работает без них).

Принципы, по которым писал: одно простое предложение для «Зачем» (без медицинских обещаний и без «снижает риск травм»), «Ошибки» — из уже существующих «На что смотреть» в `program.md` (то же, другими словами), «Команда» — короткий возглас, как у блока А.
