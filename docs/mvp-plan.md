# План MVP

Источник: живой документ «KickStart Kids: план MVP» (claude.ai). Этот файл — рабочая копия для разработки; отмечай `[x]` по мере выполнения.

**MVP** — офлайн-приложение на русском, с которым ребёнок с родителем проходит 12-недельную программу домашних тренировок. Сценарий MVP: **открыл → увидел тренировку на сегодня → прошёл её с таймером и демо → прогресс сохранился**. Всё, что не нужно для этого сценария, уходит в 1.1.

Темп: ~10 ч/нед (8 — разработка, 2 — контент). Старт 2 ноября 2026, релиз в RuStore ориентировочно к 11 апреля 2027 (с запасом 2 недели).

## Объём

| Функция | MVP | Позже (1.1+) |
| --- | --- | --- |
| Онбординг | 4 экрана: имя/возраст, дни секции и дома, дата старта, напоминания + PIN | — |
| Календарь | Генерация 12 недель, вид «месяц», отметки, секция «Был», перенос сб → вс | Вид «неделя», произвольный перенос |
| Тренировка | Проигрыватель: таймер работы и отдыха, вибрация, keep-awake, автопауза, оценка техники, итоги | Альбомный режим, озвучка команд |
| Демо | Видео с Киком для уровней 1–2; для уровней 3–5 — картинка-превью + текст | Видео уровней 3–5 |
| Библиотека | Список с фильтром по категориям, экран упражнения | Поиск |
| Прогресс | Уровни с подтверждением под PIN, серия, цель недели, мини-тесты (ввод и таблица) | Значки, графики, покрытие категорий |
| Режимы | Ребёнок и взрослый (расписание, уровни, настройки — только взрослый) | — |
| Язык | Только русский, но все строки в i18n | Английский |
| Напоминания | В дни домашних занятий | День мини-теста, настройка времени |
| Маскот Кик | Демо-видео, иконка, 3 эмоции (радость, отдых, задумчивость) | Остальные эмоции, стикеры |
| Фоны | Сгенерированные фоны для портретных экранов | Альбомные |
| Синхронизация, подписка | Нет, но `SyncMeta` и `isPremium()` закладываем | Этапы 2 и 3 плана реализации |

## Задачи

### 0. Каркас (8 ч)

- [x] Vite + React + TS strict, oxlint, Prettier, Vitest + RTL
- [x] `cap add android`; `appId` и имя в одном конфиге (`src/shared/config/app.ts`, проверяется тестом)
- [x] Роутинг: 5 табов + полноэкранные маршруты, аппаратная «Назад»
- [x] i18n с русским словарём; обёртки плагинов с веб-фолбэками (`src/shared/lib/platform`)
- [ ] Собрать debug-APK в Android Studio и поставить на телефон (`npm run cap:sync && npm run cap:open`)

### 1. UI-кит и тема (16 ч)

- [x] Шрифты Oswald и Manrope локально (без Google Fonts — приложение офлайн) (2)
- [x] Компонент фона экрана: картинка + градиенты сверху и снизу; карточка с полупрозрачной подложкой `rgba(11,42,27,0.75)` и `backdrop-filter: blur` (3)
- [x] Button, Chip, LevelPips, ProgressRing, StatRow, ExerciseCard, EmptyState с Киком (8)
- [x] RTL-тесты компонентов, контраст ≥ 4.5:1, зоны нажатия ≥ 44 px (3)

### 2. Контент и данные (16 ч)

- [ ] Zod-схемы `Exercise`, `ExerciseLevel`, `SessionTemplate` (2)
- [ ] JSON программы: 7 упражнений × 5 уровней + блоки Б–Г и игры (тексты — `docs/program.md`) (6)
- [ ] Хранилище: Preferences для настроек, SQLite/IndexedDB для журнала; слой репозиториев, `SyncMeta`, версия схемы (5)
- [ ] Сторы Effector: профиль, расписание, прогресс, настройки (3)

### 3. Онбординг и календарь (16 ч)

- [ ] 4 экрана онбординга по макетам `docs/design/Onboarding*.dc.html`, создание PIN (5)
- [ ] Генератор календаря из `Schedule` + юнит-тесты: старт не с понедельника, переход года (4)
- [ ] Экран Календаря: сетка месяца, статусы, карточка «Сегодня» (4)
- [ ] Отметка «Был» для секции, перенос сб → вс, пропуск (3)

### 4. Главная, библиотека, упражнение (16 ч)

- [ ] Главная: приветствие, серия, карточка тренировки, цель недели; день секции и день отдыха (5)
- [ ] Библиотека с фильтром по категориям (3)
- [ ] Экран упражнения: видео или превью, шаги, объём, «Зачем», ошибки для взрослого (5)
- [ ] Видео-плеер: `autoplay muted loop playsinline`, постер, «Повторить демонстрацию» (3)

### 5. Проигрыватель (24 ч)

- [ ] Сборка занятия из `SessionTemplate`: 5 частей, выбор упражнений и уровней (4)
- [ ] Машина состояний `intro → work → rest → … → sessionDone` + `paused`; время от `Date.now()`; тесты с фейковыми таймерами (7)
- [ ] Экраны таймера и отдыха; упражнения на повторы — по кнопке «Готово» (6)
- [ ] Keep-awake, вибрация на смене фазы, автопауза при сворачивании (3)
- [ ] Оценка техники, экран итогов с Киком, запись `SessionLog` (4)

### 6. Прогресс и режимы (16 ч)

- [ ] Правило повышения уровня + тесты; подтверждение под PIN (4)
- [ ] Серия и цель недели + тесты (3)
- [ ] Профиль: уровни по упражнениям, статистика (4)
- [ ] Мини-тесты: ввод и таблица (3)
- [ ] Переключатель ребёнок/взрослый, настройки расписания (2)

### 7. Напоминания и полировка (16 ч)

- [ ] Local notifications в дни домашних занятий, запрос разрешения, перепланирование при переносе (5)
- [ ] Иконка, сплэш, статус-бар (2)
- [ ] E2E в браузере: онбординг → календарь → тренировка → прогресс (4)
- [ ] Проверка на слабом телефоне, размер APK, правки (5)

### 8. Бета (16 ч)

- [ ] 2 недели занятий по приложению, замечания после каждого
- [ ] Исправить критичные и серьёзные баги; мелочи — в бэклог 1.1

### 9. Публикация (10 ч)

- [ ] Подписанный APK/AAB, `versionCode` 1
- [ ] Политика конфиденциальности: данные только на устройстве
- [ ] Карточка в RuStore: описание, скриншоты, возрастной рейтинг, без бренда FIFA
- [ ] Модерация

## Критерии готовности к релизу

- [ ] Онбординг → календарь на 12 недель меньше чем за 2 минуты
- [ ] Занятие проходится целиком без сбоев, в том числе при блокировке экрана, сворачивании и звонке
- [ ] Прогресс, уровни и серия переживают перезапуск приложения и телефона
- [ ] Всё работает в режиме полёта
- [ ] У каждого упражнения есть текст и видео или превью; видео прошли чек-лист приёмки
- [ ] Повышение уровня и настройки недоступны без PIN
- [ ] Напоминания приходят, в том числе после перезагрузки телефона
- [ ] Юнит-тесты бизнес-правил и E2E зелёные
- [ ] 2 недели беты без критичных багов
- [ ] Политика конфиденциальности опубликована, бренда FIFA нет

## Что резать, если не успеваем

1. Мини-тесты → на бумаге (−3 ч)
2. Видео блоков Б–Г → превью-картинки (−7 ч)
3. Фоны для каждого экрана → один общий (−4 ч)
4. Экран итогов → простое окно «Тренировка завершена» (−2 ч)
5. Перенос занятия → только «пропущено» (−2 ч)
